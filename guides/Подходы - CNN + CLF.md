# Идея

### Архитектура конвейера

Подход состоит из двух ключевых стадий, которые работают последовательно:

#### **Стадия 1: Классификация на уровне изображений**

На первом этапе конвейера используется **сверточная нейронная сеть (CNN)**.

Эта модель специализируется на анализе отдельных изображений (2D-срезов).

- **Вход:** Каждый отдельный срез КТ-изображения.
    
- **Модель:** Обычно используется предобученная архитектура, например **EfficientNet-b3**.
    
- **Задача:** Для каждого среза модель определяет, есть ли на нем признаки ТЭЛА. На выходе она генерирует не просто бинарный ответ, а **вектор признаков** — числовое представление, которое содержит всю извлеченную информацию о срезе.
    

Таким образом, на этом этапе каждый срез превращается в своего рода "сжатое" описание, которое содержит в себе всю необходимую информацию для следующей стадии.

#### **Стадия 2: Классификация на уровне всего исследования**

На втором этапе в дело вступает вторая модель, которая анализирует уже не изображения, а **последовательность векторов**, полученных на первой стадии.

- **Вход:** Вся последовательность векторов признаков, сгенерированных на Стадии 1.
    
- **Модель:** Для анализа последовательностей часто используются **двунаправленная долгая краткосрочная память (Bi-LSTM)** или **многослойный перцептрон (MLP)**.
    
- **Задача:** Модель анализирует всю последовательность, чтобы найти закономерности между срезами. Например, она может понять, что тромб "тянется" через несколько срезов, и на основе этого принять итоговое решение о наличии ТЭЛА во всем исследовании.
    

На этом этапе происходит агрегация информации и финальная бинарная классификация.
